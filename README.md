# Bolt Inspection & Training — Website

Corporate website for an inspection and training company, built with Flutter Web. Includes a hidden admin panel for managing site content and contact submissions.

## Features
- Marketing site: home, services, about, contact, certifications
- Admin panel (login-protected): content editor, contact inbox, media manager
- Contact form backed by Cloud Firestore

## Tech Stack
Flutter · Dart · Firebase Authentication · Cloud Firestore

## Run
```
flutter pub get
flutterfire configure
flutter run -d chrome
```
