# Bolt Inspection & Training — Website

Corporate website for an inspection and training company, built with Flutter Web. Includes a public marketing site and a hidden Firebase-backed admin panel for managing site content, contact submissions, and media.

## Features

**Public site**
- Home, services, about, and contact pages with responsive layouts
- Service detail pages and certification badges
- Contact form wired to Cloud Firestore

**Admin panel** (hidden route, email/password login)
- Dashboard with submission overviews
- Contact message inbox — read, reply tracking, delete
- Site content manager — edit homepage content without touching code
- Media manager for site assets

## Tech Stack
- Flutter (Web) · Dart
- Firebase Authentication, Cloud Firestore
- Material 3 theming

## Getting Started

```bash
flutter pub get
```

### Firebase setup

1. Install the FlutterFire CLI: `dart pub global activate flutterfire_cli`
2. Run `flutterfire configure` and select your Firebase project (Web platform). This generates `lib/firebase_options.dart`.
3. Enable **Email/Password** sign-in under Authentication.
4. Create a Firestore database and apply these security rules:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /contact_submissions/{docId} {
      allow create: if true;
      allow read, update, delete: if request.auth != null;
    }
    match /site_content/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

5. Create the admin user under Authentication → Users (there is no public sign-up by design).

### Run & build

```bash
flutter run -d chrome      # local development
flutter build web          # production build
```

## Project Structure

```
lib/
  main.dart               — app entry, routing, Firebase init
  firebase_options.dart   — generated by flutterfire configure
  theme/                  — brand colors and ThemeData
  models/                 — data classes
  services/               — Firebase Auth + Firestore wrappers
  widgets/                — shared UI (nav, footer, cards, forms, admin shell)
  screens/                — one file per page
  screens/admin/          — admin panel screens
assets/
  logos/ images/ certifications/
web/                      — Flutter web shell, PWA manifest and icons
```
